Dijkstra's Algorithm
⏱ O((V + E) log V)
Key Note: Push {dist, u} to min-heap. Skip visited nodes if d > dist[u].
using pli = pair<long long, int>; void dijkstra(int src, int n) { priority_queue<pli, vector<pli>, greater<pli>> pq; dist.assign(n + 1, INF); dist[src] = 0; pq.push({0, src}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (d > dist[u]) continue; for (auto& [v, w] : adj[u]) { if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; pq.push({dist[v], v}); } } }

Coordinate Compression
📝 NOTE

Core Steps:

  • Collect coordinates: vals.push_back(x);
  • Sort & remove duplicates: sort(all(v)); v.erase(unique(all(v)), v.end());
  • Query compressed rank: lower_bound(all(v), x) - v.begin();

Edge Cases: For 1-based indexing, add + 1 to the rank. Retain the vector for inverse lookup v[rank].

Note Card Example
DATA STRUCTURES // NOTE 01 OBSERVATION
Coordinate Compression Guidelines
• Domain: ≤ 10⁹ • Space: O(N) • Query: O(log N)

Procedure:

  • 1. Aggregate queries into vector<int> v;
  • 2. Sort & compact: sort(all(v)); v.erase(unique(all(v)), v.end());
  • 3. Binary search rank: lower_bound(all(v), x) - v.begin();

Important: If Fenwick / BIT used, 1-index required (add + 1).
